# ZUP Kazakhstan

ЗУП для Казахстана на платформе lsFusion.

## Рабочая среда

Репозитории располагаются рядом:

```text
~/workspace/
├── platform/   # fork erkevibe/platform, ветка develop
└── zup-kz/     # прикладная логика
```

`pom.xml` подключает Maven parent из `../platform/build/logics/pom.xml`, поэтому приложение собирается на базе локального форка, а прикладной код не смешивается с ядром.

## Сборка

```bash
mvn --batch-mode clean package
```

Настройки конкретной установки не коммитятся. Скопируйте `conf/settings.properties.example` в `conf/settings.properties` и задайте пароль БД.

## Модули

- `core` — организации и общие справочники;
- `hr` — сотрудники, подразделения, должности, кадровые события;
- `time` — графики и табель;
- `payroll` — начисления и удержания;
- `taxeskz` — правила и ставки РК;
- `reportskz` — регламентированная отчётность и печатные формы;
- `integration` — банки, 1С, государственные сервисы.

На первом этапе реализованы организация, подразделение, должность, сотрудник и приём на работу.
