# Безопасность

Не публикуйте уязвимости в обычных GitHub Issues. Используйте приватный раздел
**Security → Advisories → Report a vulnerability** репозитория.

В сообщении укажите затронутую версию, сценарий воспроизведения, ожидаемое
влияние и безопасный способ проверки. Не прикладывайте реальные ИИН, зарплатные
данные, пароли, ключи ЭЦП или дампы рабочих баз.

До появления стабильного релиза исправления безопасности выпускаются для
актуальной ветки `develop`. Поддерживаемые релизные ветки будут перечисляться
в этом файле после первого промышленного релиза.
