# Журнал изменений

Значимые изменения проекта фиксируются здесь. Версии следуют Semantic Versioning.

## Unreleased

### Added

- Единая закреплённая ревизия платформы и воспроизводимый скрипт сборки.
- Отдельные статический и серверный CI-гейты с ограничением времени запросов.
- Безопасный populated-DB restore/upgrade drill со сверкой строк,
  идентификаторов и ключевых расчётных итогов.
- Проверки принадлежности смен, дней циклов и назначений графиков.
- Проверки цифрового формата ИИН/БИН и базового формата IBAN/БИК.
- Негативные серверные тесты новых ограничений.
- Проверки непрерывности циклов, обязательного начала цикла и соответствия часов смены.
- Подтверждение критических отменяющих, закрывающих и сторнирующих действий.
- Серверные негативные тесты межорганизационного изменения master data,
  черновиков, расчётов, владельца объекта и удаления под бизнес-ролями.
- Серверные guards для вторичных кадровых, расчётных, налоговых и отчётных
  документов и строк; CI-проверка полного покрытия 71 организационного типа.

### Changed

- Тестовые lsFusion-модули вынесены из production-ресурсов в профиль
  `test-logics`; обычный JAR больше не содержит тестовых действий.
- GitHub Actions workflow сокращён: серверная регрессия вынесена в локально
  запускаемый `scripts/ci-runtime-regression.sh`.
- Личная карточка и кадровое рабочее место разделены на компактные вкладки.
- Технические коды нормативных справочников перемещены после пользовательских названий.
- QA-формы, системное администрирование и режим дизайна скрыты от бизнес-ролей.
- Текущая должность и оклад договора читаются из кадрового назначения; старые поля
  сохранены только для совместимости существующих данных и убраны из редактируемого UI.
- Lifecycle-токены согласований, архива и страхования привязаны к конкретному объекту.
- Доступ к организациям теперь проверяется при обычном изменении и удалении
  базовых кадровых данных, личных карточек, графиков, табелей и исходных расчётов.
- Та же проверка распространена на отпуска, командировки, согласования, архив,
  страхование, больничные, перерасчёты, взыскания, выплаты, налоговые документы,
  социальные реестры и форму 200.00/200.05.

## 0.1.0-alpha

- Первый связный технический MVP кадров, времени, зарплаты, налогов РК и формы 200.
