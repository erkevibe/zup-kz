# Проверка релиза

## До слияния в `main`

1. Рабочее дерево чистое, pull request в `develop` проверен CI.
2. `./scripts/check.sh` и `./scripts/build.sh ../platform` завершены успешно.
   Скрипт сборки сам проверяет commit платформы; production JAR не содержит
   модулей `*Test.lsf`. Функциональные серверные сценарии выполняет CI.
3. Актуальная версия приложения запущена на восстановленной копии наполненной базы.
4. Проверены роли кадровика, табельщика, расчётчика, главного бухгалтера и аудитора.
5. Для изменений расчёта приложены нормативный источник и контрольные суммы.
6. Создан и проверен резервный архив; документирован откат приложения и базы.
7. `CHANGELOG.md` обновлён, версия больше не содержит `SNAPSHOT`.

## Выпуск

1. Слить `develop` в `main` без переписывания истории.
2. Создать подписанный тег `vX.Y.Z` на коммите `main`.
3. Опубликовать артефакт, SHA-256, миграционные замечания и changelog.
4. После развёртывания проверить `/main`, вход каждой роли и один сквозной расчёт.

Не помечайте выпуск промышленным до юридической приёмки расчётов и официальных
форматов, настройки HTTPS, внешней резервной копии и мониторинга.
